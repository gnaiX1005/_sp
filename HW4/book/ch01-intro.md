# 第一章：系統程式概論

## 1.1 什麼是系統程式

系統程式（Systems Programming）是電腦科學中基礎且關鍵的一環。與應用程式（Application Programming）不同，系統程式專注於提供底層基礎設施，讓應用程式能夠順利執行。

系統程式的主要範疇包括：

- **編譯器（Compiler）**：將高階語言轉換為機器碼
- **直譯器（Interpreter）**：直接執行原始碼
- **作業系統（Operating System）**：管理硬體資源與行程排程
- **組譯器（Assembler）**：將組合語言轉換為機器碼
- **連結器（Linker）**：將多個目的檔結合成可執行檔
- **載入器（Loader）**：將可執行檔載入記憶體
- **虛擬機（Virtual Machine）**：軟體模擬的執行環境

## 1.2 編譯器 vs 直譯器

編譯器和直譯器是兩種將程式碼轉換為可執行形式的主要方式。

### 編譯器

編譯器將原始碼全部轉換為機器碼後再執行，常見的 C/C++、Rust、Go 都屬於編譯語言。

```
原始碼 → 詞法分析 → 語法分析 → 語意分析 → 中間碼生成 → 最佳化 → 機器碼生成 → 可執行檔
```

### 直譯器

直譯器逐行讀取並執行原始碼，不產生獨立的可執行檔。Python、JavaScript、Ruby 屬於直譯語言。

```
原始碼 → 詞法分析 → 語法分析 → AST → 直譯執行
```

### 兩者比較

| 特性 | 編譯器 | 直譯器 |
|------|--------|--------|
| 執行速度 | 快（已編譯為機器碼） | 慢（逐行解譯） |
| 啟動時間 | 需先編譯 | 立即執行 |
| 偵錯 | 較困難 | 較容易 |
| 可移植性 | 需針對不同平台編譯 | 有直譯器即可執行 |

## 1.3 為什麼要學系統程式

學習系統程式有以下好處：

1. **深入理解電腦運作原理**：了解程式碼是如何被電腦理解和執行的
2. **提升程式設計能力**：系統程式需要嚴謹的思維，能大幅提升程式設計能力
3. **開發高效能應用**：理解底層機制後，能寫出更有效率的程式
4. **貢獻開源專案**：許多重要的開源專案（如 LLVM、Linux）都是系統程式

## 1.4 本涵蓋的主題

本書將從實作的角度，帶領讀者一步步建立一個完整的程式語言直譯器。我們會先實作詞法分析器和語法分析器，接著建立抽象語法樹（AST），然後實作樹狀走訪直譯器。

最後，我們還會探討作業系統、RISC-V 組合語言、網路程式設計等主題，並介紹如何運用 AI 工具來加速系統程式的開發。

- 系統程式是電腦科學的基礎
- 編譯器將原始碼轉換為機器碼；直譯器直接執行原始碼
- 學習系統程式能深入理解電腦原理、提升程式能力
- 本書將從實作角度，帶領讀者打造完整的直譯器
